Matching 715 ministry asset records across mismatched datasets

professional · Ministry of Infrastructure, Corporate Management Unit · May – Aug 2026 · R, tidyverse

OBJECTIVE

The ministry's Infrastructure Modelling and Intelligence units needed one clean list of facilities to feed predictive software that forecasts infrastructure needs. The same facilities were recorded across several datasets with different IDs and naming conventions, so the job was to join mismatched records reliably.

WORK

  • Built an automated pipeline in R (tidyverse) that merges records from multiple sources using a cascade approach to prioritize reliable sources.
  • For facilities with no shared ID across datasets, built a TF-IDF text-matching tool to match across different naming conventions, with a confidence score to flag unreliable matches.
  • Went through multiple rounds of user review to adapt the tool to the team's needs.

RESULTS

  • Matched and cleaned 715 asset records from separate ministry datasets.
  • Removed all duplicate and conflicting records.
  • Matched 100% of facilities which existed in the given datasets.
  • Recovered all the missing facilities which the team was searching for manually prior to the project.

WHAT I LEARNED

  • Learned the process in which code is scrutinized and implemented by senior staff.
