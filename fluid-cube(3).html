Building a handheld water simulation you can tilt

personal · in progress · rp2040, c++, python

OBJECTIVE

Build a palm-sized cube with a small screen that shows water sloshing inside it. Tilt the cube and the water moves as if it were really there.

CONCEPT

  • An MPU6050 motion sensor measures which way gravity points as the cube is tilted.
  • A Seeed Studio RP2040 board runs a FLIP water simulation: particles carry the water, and a grid keeps it from compressing.
  • The water is drawn on a 1.5" SH1107 OLED screen on one face of the cube.
  • The frame is a soldered 2 mm brass-rod cube about 2" on each side, wired with 0.9 mm brass wire, with a TP4056 module for battery charging.

APPROACH

  • Prototype the simulation in Python first, then port it to C++ for the RP2040.
  • Following Matthias Müller's "How to write a FLIP water simulator" (Ten Minute Physics) as the reference method.

STATUS

In progress. Photos, code and results will be added as the build continues.
